INFONEXT UK WEBSITE
===================

Files:
- index.html       Main website
- styles.css       Colours, layout and responsive design
- script.js        Mobile menu + copyright year
- assets/          Logo and favicon

Quick preview:
Double-click index.html on a computer to open the site locally in a browser.

Before publishing:
1. Add your WhatsApp, Facebook and Instagram links once you know their exact URLs.
2. If you want an online contact form that sends without opening the visitor's email app,
   connect a form service or hosting function. The current form safely uses mailto:.
3. Review prices and wording before launch.

Free hosting suggestions:
- GitHub Pages: supports custom domains on GitHub Free. You can point DNS records from IONOS
  without moving your email service.
- Cloudflare Pages: static sites can be hosted free with a custom domain. Moving the apex
  domain to Cloudflare requires careful copying of IONOS email DNS records.
